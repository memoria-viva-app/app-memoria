# Reglas del Proyecto

- **Commit automático**: Después de realizar y verificar cualquier cambio en el código o archivos del proyecto (asegurando que la compilación pase sin errores), haz siempre un `git commit` automático con un mensaje claro y descriptivo en español siguiendo el estilo del repositorio. No hagas `git push` salvo que el usuario lo pida explícitamente.
