# Reglas del Proyecto

- **Commit y push automático**: Después de realizar y verificar cualquier cambio en el código o archivos del proyecto (asegurando que la compilación pase sin errores), haz siempre `git commit` y `git push` automáticamente con un mensaje claro y descriptivo en español siguiendo el estilo del repositorio, para que los cambios queden subidos y desplegados en GitHub Pages.
